# Sign Language Translator Mobile App

Flutter foundation for the Sign Language Translator mobile application.

## Requirements

Install Flutter SDK and make sure `flutter` is available on PATH.

## Run

```powershell
cd "D:\sign langauge project\application"
flutter pub get
flutter run
```

If native platform folders are missing, run:

```powershell
flutter create .
flutter pub get
flutter run
```

This phase includes app structure, routing, theme, and placeholder screens only. Camera, backend calls, and AI inference are intentionally not implemented yet.
